# ONNX Graph Preview v0.3.0

Every graph now carries a view toggle in its top corner that flips the fence between the graph and its source text, highlighted the way the preview highlights any code block. A flipped fence stays flipped while you edit the document, after *Markdown: Refresh Preview* and when the preview is reopened. The toggle is also present on error cards, and it is a reader's control: no fence attribute presets it.
